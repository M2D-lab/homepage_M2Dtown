# homepage_M2Dtown — 材料創製力学研究室（M2D-lab）ホームページ「M2D TOWN」

公開 URL: https://m2d-lab.github.io/homepage_M2Dtown/

トップページに **傘のように広がる一本の大木を中心にした小さな町** の 3D 模型を置き、町の中の目印から各項目を開く構成。
右上に角の丸い帯のナビ（ホーム・メッセージ・お知らせ・研究室・お問い合わせ・アクセス）を常に表示する。「研究室」には研究室概要・研究テーマ・業績・装置・設備・学生の声・メンバー、「お問い合わせ」には学生の方へ・企業の方へ・一般の方へ・お問い合わせフォームがドロップダウンで入る。ナビの項目と町の目印は、どちらも押すとその項目のページ（全画面）へ移動する。
季節（春: 桜 / 夏: 広葉樹 / 秋: 紅葉 / 冬: 雪の裸木）と配色（黄・紺・緑・黒）はナビの下の「町の天気」にカーソルを載せると出る切替で変えられる（選択はブラウザに記憶。季節の初期値は今日の日付から決まる）。

## 更新のしかた

日常の更新（お知らせ・メンバー・業績・装置・写真・学生の声）は [更新の仕方.md](更新の仕方.md) の手順書を参照。触るのは `src/content/` のデータファイルと `public/images/` の画像だけで、ビルド後に `npm run check` がリンク切れ・画像欠けを点検する（GitHub Actions でも自動実行）。

## 構成

| パス | 内容 |
|---|---|
| `src/pages/index.astro` | トップ（タウンビュー）。3D キャンバスの上に見出し・目印・目印の説明（お知らせは直近 5 件）を重ねる |
| `src/scripts/diorama.js` | three.js の 3D シーン。芝生の広場と環状の道、大木（幹・枝は固定、樹冠と雪は季節で生成）、季節の粒子、研究棟・講義棟・食堂・売店、木、研究者、キャッチボールの 2 人、旋回する飛行機、電子顕微鏡、立て看板、郵便受け、M2D の文字。季節は先頭の `SEASONS`、配色は `THEMES` で調整 |
| `src/components/SiteChrome.astro` | 全ページ共通の、右上のナビ（ドロップダウン付き）と「町の天気」（季節・配色） |
| `src/lib/town.ts` | ページの一覧（`PLACES`）と、ナビの項目・並び順・サブ項目（`NAV`） |
| `src/content/` | 内容のデータ（お知らせ・メンバー・業績・装置・研究テーマ・学生の声・お問い合わせの対象別案内） |
| `src/layouts/Base.astro`, `src/scripts/transitions.ts` | 文章ページの共通レイアウトと flipX のページ切替（Astro View Transitions） |
| `public/style.css` | ページの見た目。`:root[data-theme="yellow|black"]` で配色を切替 |
| その他のページ | トップと同じ配色・ナビ・パネル表示に統一 |

- 3D は [three.js](https://threejs.org/)（MIT ライセンス）を npm で導入。モデルファイルや画像は使わず、すべてコードで組んでいる。
- マウスの動きで模型が傾き、スクロールでゆっくり回る。`prefers-reduced-motion` が有効な環境では動きを止める。
- 立方体の数は約 4,000 個を 1 つの InstancedMesh にまとめており、スマートフォンでも動く想定（要実機確認）。
